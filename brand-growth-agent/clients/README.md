# Clients

كل عميل ليه فولدر `clients/<client-slug>/` بالهيكل اللي في T10 (`agent/templates/templates.md`).
الملف `_learnings.md` فيه الأنماط اللي بتتكرر بين العملاء، من غير أي بيانات تكشف عميل بعينه.

⚠️ متحطش بيانات شخصية (أسماء، أرقام تليفونات، بيانات مرضى) في الريبو، خصوصاً لو public. الـ exports الخام تفضل عندكم.
